# This project has moved to `kikuchi-sphere-interactive`.

**[正式项目 / Active repository](https://github.com/AbigaleLu/kikuchi-sphere-interactive)** · **[打开交互模型 / Open website](https://abigalelu.github.io/kikuchi-sphere-interactive/)**

本仓库仅用于兼容之前分享的 GitHub Pages 地址，不包含模型、贴图或统计代码。

- `index.html`、`index-lite.html`、`index-drawings.html` 自动前往新站相同路径。
- 查询参数和锚点原样保留，包括 crystal、edition、q、zoom 和 face。
- `404.html` 尝试将旧深层地址转到新站相同路径；目标仍须在新站存在。
- 使用 `location.replace`，避免浏览器后退时反复进入旧跳转页。
- JavaScript 被禁用时提供新站首页链接。
- 无额外访问统计；访问只由正式项目统计。

GitHub Pages 使用 main 分支根目录发布。这里是浏览器端兼容跳转，不是服务器 HTTP 301；404 回退不适用于程序化资源请求。

旧 GitHub 仓库链接现在打开本迁移说明；其他电脑的正式项目克隆应将 origin 更新为 `https://github.com/AbigaleLu/kikuchi-sphere-interactive.git`。
